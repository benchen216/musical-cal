# 幕間・台灣音樂劇日曆

台灣音樂劇日曆的靜態網站程式碼與公開演出資料備份。

## 本機預覽

在此資料夾執行 `python3 -m http.server 8000 --directory dist`，再開啟 http://localhost:8000 。不需要安裝前端套件或編譯。

## 檔案

- `dist/index.html`：網站頁面。
- `dist/styles.css`：樣式與原創 CSS 視覺。
- `dist/app.js`：互動日曆、篩選及搜尋。
- `dist/model.js`：日期與資料邏輯。
- `dist/events.js`：公開演出資料及官方來源連結。
- `tests.cjs`：執行 `node tests.cjs` 驗證資料與日期邏輯。

## 資料範圍

此版本於 2026-10-22 核對，涵蓋 2026-10-22 至 2027-01-21 的部分台灣音樂劇場次，共 6 部作品、41 場演出。這不是完整節目表，也不提供即時售票狀態。購票前請依官方最新公告確認。

此備份不包含主機設定、憑證或自動更新服務。更新此儲存庫不會自動更新已發布的網站。
