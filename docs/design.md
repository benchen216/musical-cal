# 介面設計參考與取捨

核對日期：2026-10-22。這是介面研究筆記，不是演出資料來源。參考各站的資訊層級，不複製品牌、程式、照片或標誌。

## 實際參考

- [HAU：Schedule & Tickets](https://www.hebbel-am-ufer.de/en/programme/schedule-tickets)：官方頁面將月份、日期、時間、場館、創作人、節目與票務分層；瀏覽器觀察可見篩選列與日期／節目區分欄。採用清楚的時間與地點層級，而非依海報大小決定閱讀順序。
- [Berliner Ensemble：Spielplan](https://www.berliner-ensemble.de/spielplan)：實際列表視覺以大日期、不同字重、橫線與右側固定票務位置組織，不必把每一場裝成圓角卡片。採用日別索引與對齊票務位置，不沿用其黑黃配色、字標或售罄狀態。
- [The Yard Theatre](https://www.theyardtheatre.co.uk/)：實際首頁有鮮明字標、強烈字體比例與不對稱版面，並大量依賴劇照。參考其品牌辨識原則，不複製劇照或標誌；本站沒有取得劇照授權，保留原創文字與 CSS。

另有官方資訊架構參考：[Schaubühne](https://www.schaubuehne.de/de/spielplan/programm.html)、[Berlin Bühnen](https://www.berlin-buehnen.de/en/schedule/)。僅查閱其節目欄位與篩選內容，未將它們當作已完整視覺驗證的範例。

## 本站的具體變更

1. 首頁是節目索引，不是宣傳頁。縮小引言，保留「臺北，最近有什麼戲？」與清楚的收錄期間。
2. 桌面以窄欄篩選、月份索引配上日期排列節目；手機改成可展開的篩選及橫向月份索引。
3. 劇名、開演時間、場館、官方購票位置固定；節目介紹與售票／早鳥分別按需展開，避免長簡介淹沒場次。
4. 天候、停演、取消、改期等已記錄提醒不因精簡版面而藏起。
5. 保留幕間名稱、紙色與深紅色，但以字標比例、欄寬、字重和閱讀密度建立辨識，不靠無關裝飾。
6. 不改動演出資料、臺北預設、其他城市、日期排序、月曆、劇場與劇團目錄、地圖及創作者連結。

## 維護

節目索引的新版樣式集中在 `dist/programme.css`。新增資料時沿用既有欄位，不依某部作品改動版面，也不置頂作品。月份由收錄範圍動態產生，月份數字顯示該條件下已收錄場數，不代表全市場場數。手機篩選應可用鍵盤展開；介紹與票務預設收起。窄螢幕不要以隱藏場次、場館或購票資訊解決溢位。
