# 資料整理與更新原則

幕間以靜態 HTML、CSS 與 JavaScript 提供音樂劇日曆、雙北場館資訊及創作團隊選集。它不是全臺完整演出資料庫，也不是即時售票系統。

## 來源優先順序與搜尋範圍

1. 以主辦單位、製作團隊、演出場館及正式售票平台公告為準。
2. 每次發掘新節目時，交叉搜尋 OPENTIX、TixFun、年代售票、寬宏售票，以及劇團與場館官方節目頁。不能只重查已收錄的作品。
3. 同時照顧北、中、南與小、中型製作，包含原創、授權改編、親子與沉浸式音樂劇；音樂劇讀劇音樂會須明確另標形式，不能冒充完整舞台製作。新聞及搜尋摘要可以提供線索，但不能直接當作確定場次的依據。
4. 每輪另外逐一核對已知製作團隊的近期節目，並以作品正式名稱與主辦名稱交叉搜尋。首頁、主題頁及搜尋結果不是完整清單；同系列的新作不能因名稱相似而省略。
5. 公司與場館目錄是精選，不是排名。場館、廳別、劇團、工作室與製作公司分開辨識；不推測人數、營收或經營規模。

## 預設瀏覽與排序

- 首頁預設使用按日期排列的節目單，保留一鍵切換月曆；票務詳情預設收合。版面是觀劇手冊形式，不提供私人筆記儲存或後端資料庫。
- 新開頁面預設城市為臺北市，不包含新北市；保留全臺、地區及其他城市選項，預設值不縮減蒐集範圍。
- 演出依日期、開演時間排序。同日同作品可合併顯示各場時間，但不因個人關注、補登日期或來源順序置頂。

## 收錄與去重

- 日曆以臺灣時間整理未來約三個月的已確認演出，實際範圍由頁面標示。為新公告的有效場次延伸範圍時，必須同步核對資料及日期說明。
- 每場必須有作品、城市、正確場館／廳別、日期、時間、官方來源與核對日期。只有演出期間而沒有逐場時間的資訊，先列為待核對，不猜測補齊。
- 同作品以穩定作品識別碼關聯；不同城市或場館可分成巡演站。以巡演站識別碼＋日期＋時間去重，避免跨平台重複列入。
- 不是所有音樂、歌舞或戲劇節目都是音樂劇。依官方對節目的分類與介紹判斷，不為了增加數量混入純演唱會、讀劇課程或非公開排練。
- 活動取消、延後或更改場次時保留清楚的核對依據，不能把舊時段當作仍有效的演出。

## 售票與早鳥資訊

- 開賣日、開賣時分及早鳥方案獨立核對。預售、會員優先購與全面啟售不能混為一談。
- 未確認的時間或折扣明寫未知，不補成00:00，也不把文章發布日或套票起售日當作一般票開賣日。
- 優惠顯示適用期間、折扣、會員／票區／最低價限制及官方購票連結。過期方案標為「已結束」，歷史公告不能暗示仍可使用。
- 優惠狀態與即時餘票是兩件事。頁面不宣稱有票、售罄或保證折扣，購票資格與可用席位以官方結帳頁為準。
- 售票資料預設收在可展開區塊內，讓手機上的場次卡片保持簡潔。

## 颱風與條件式場次

- 保留官方天候、停演及改期提醒，並連結原公告。
- 「如果某日停演，將加開另一日」只是備案，必須等主辦正式確認後才能列入日曆。
- 社群最新公告無法讀取時說明限制，不用舊售票頁推定最新演出一定照常。

## 圖片、地圖與場地資料

- 引用來源不等於取得圖片授權。未取得適用使用權的劇照、海報及標誌不複製到本站。
- 目前介面採原創 CSS 視覺。若日後使用授權圖片，記錄權利人、授權範圍、來源與必要署名。
- Google Maps 連結以已核對場館名稱和完整地址產生搜尋，不猜測地點識別碼。觀眾仍應確認當場演出的廳別與入口。
- 座位數依官方最新技術資料優先；可變配置、輪椅席／陪同席及舊資料限制清楚標註，不把可變數字寫成保證售票量。

## 有變更才發佈與備份

- 每日檢查可以沒有變更。只有新節目、場次異動、開賣／優惠公告或實質資料更正才提交與發佈。
- 不為了換核對時間戳、調整格式或移動沒有新增內容的日期範圍而提交空更新。未變更的記錄保留上次公開核對日期。
- 更新前確認目前版本；保留無關修改。驗證資料格式、場次去重、日期／時區、地區篩選、目錄搜尋及優惠過期規則。
- 靜態資料更新需要重新發佈。必須驗證正式網站成功開啟及改動內容後，才稱為網站更新完成。
- 每次有變更的發佈都同步備份公開來源、資料、測試及這份說明到本 repository。不要納入憑證、部署身分設定、私有維護指令、快取或本機封裝。
- 網站與 GitHub 備份分別驗證；若只有一邊成功，應明確回報部分完成。重試前先檢查實際結果，避免重複寫入；不能為重試備份而再次發佈相同網站。

## 開發與檢查

主要資料位於 `dist/events.js`、`dist/ticket-data.js`、`dist/guides-data.js`。使用 Node.js 執行：

- `node tests.cjs`
- `node guides-tests.cjs`
- `node ticket-tests.cjs`

日曆與目錄資料應維持可讀、可追溯。來源查核紀錄見 [sources.md](sources.md)。
